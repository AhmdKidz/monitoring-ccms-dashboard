# Monitoring CCMS & Administrasi Kontrak Dashboard (Divisi Infrastruktur 1)

Dashboard pemantauan kepatuhan administrasi kontrak (20 parameter dokumen kontraktual) untuk 51 proyek di Divisi Infrastruktur 1.

## 🚀 Fitur Utama
- **UI/UX Google Stitch Aesthetic**: Desain modern, responsif, dark/light mode, dengan glassmorphism dan tipografi Plus Jakarta Sans.
- **100% Real-time / Live Sync**: Mengambil data langsung dari Google Sheets via Google Visualization API tanpa backend/database tambahan.
- **Automated KPI Cards**: Rekapitulasi kepatuhan total divisi, proyek 100%, perlu tindak lanjut, dan zona kritis.
- **Interactive Charts**: Leaderboard komparasi Departemen Operasi (DO 1, DO 2, DO 3) dan Analisis Bottleneck 20 dokumen.
- **Multi-dimensional Filter**: Filter departemen, status kepatuhan, dan pencarian instan nama proyek.
- **Audit Detail Modal**: Ceklis interaktif 20 dokumen per proyek dengan status ✓ Lengkap / ✗ Belum Ada.
